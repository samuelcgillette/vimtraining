# Vim Training

A hands-on practice file for learning Vim, about 15 minutes long.

## Get started

```bash
git clone https://github.com/samuelcgillette/vimtraining.git
cd vimtraining
vim vim-practice.txt
```

Follow the instructions at the top of the file. Each lesson explains one command and gives you 5 exercises.

## Start over

If you saved changes and want a fresh copy:

```bash
git checkout vim-practice.txt
```
